# Neptunium External v1.0

Минимальный Android-проект внешнего оверлея. Он показывает плавающую кнопку и меню поверх других приложений, а также отдельный экранный прицел. Проект **не внедряется** в Standoff 2, не читает память игры и не взаимодействует с её процессом.

## Сборка APK без установки Android Studio на ПК

1. Создай репозиторий на GitHub через браузер телефона.
2. Загрузи в него содержимое этой папки (не сам ZIP).
3. Открой вкладку **Actions**.
4. Выбери **Build Neptunium APK** и нажми **Run workflow** (или дождись сборки после загрузки файлов в `main`).
5. Открой завершённый запуск workflow и скачай артефакт `Neptunium-External-debug`.
6. Распакуй скачанный ZIP — внутри будет `app-debug.apk`.

## Установка и запуск

1. Установи APK на Android 8.0 или новее.
2. Открой Neptunium и нажми «Запустить Overlay».
3. В настройках Android разреши «Показывать поверх других приложений».
4. Вернись в Neptunium и нажми запуск ещё раз.
5. Открой Standoff 2. Кнопку `N` можно перетаскивать; нажми её, чтобы открыть меню.

## Примечания

- Для стабильной работы Android показывает постоянное уведомление о работающем сервисе.
- Если система выгружает приложение, отключи для Neptunium агрессивную оптимизацию батареи.
- Это стартовый исходный проект. APK здесь заранее не собран; GitHub Actions собирает его в облаке.
